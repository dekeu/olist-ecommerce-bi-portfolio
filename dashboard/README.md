# Interactive Tableau Dashboard

## Olist E-Commerce Performance and Delivery Analytics

This interactive Tableau workbook contains three dashboard pages:

1. Executive Overview
2. Delivery & Customer Experience
3. Product Performance

## Tools Used

- Tableau Public
- DuckDB
- SQL
- CSV
- Visual Studio Code

## Dashboard Focus

The workbook explores:

- Delivered GMV and order volume
- Customer reach by state
- Monthly sales performance
- Delivery reliability
- Customer review scores
- Product-category performance
- Freight-to-GMV pressure

The analysis uses historical Olist e-commerce data from approximately 2016–2018.
